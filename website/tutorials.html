Windows:

Instead of using windows, like a baffoon you should use a distribution(distro) of linux. There are a lot of them, so the choice can be very daunting. Here are some of our suggestions to best suit your needs:

If you don´t want to use a terminal at all, we recommend linux mint. It is very stable and looks similar to windows. Less customisable, but very good for daily driving. Lindows is also an option (not linspire, see lindows.org), but it is far less stable. For gaming, we recommend bazzite or SteamOs, with enhanced performance. Bazzite is a little higher maintainance, but worth it for a dedicated gaming machine. If you are willing to use the terminal on occasion, try Ubuntu, or if you want something even more stable, try debian. If you want newer features, try fedora. it is higher maintainance, but very efficient when used right. If you are a massochist and enjoy suffering and buggy, untested updates every two days, use arch.
